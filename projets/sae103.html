Le projet en bref

Première vraie incursion dans l'administration système. Il fallait installer une machine virtuelle Debian sous VirtualBox, puis y configurer un serveur LAMP complet : Linux, Apache (serveur web), MySQL (base de données), PHP (langage côté serveur).

L'objectif : avoir un environnement de développement web fonctionnel, comme dans une vraie entreprise. Tout faire en ligne de commande, ce qui m'a forcé à comprendre ce que je faisais — pas juste cliquer sur « Suivant ».

Comment ça s'est déroulé

Installation de VirtualBox + Debian

Téléchargement de l'ISO, création de la VM, première connexion en ligne de commande.

Configuration du serveur LAMP

apt install apache2, configuration PHP, création de la base MySQL.

Tests et page web fonctionnelle

Mise en place d'un fichier info.php, vérification des modules Apache, premier site dynamique.

Rédaction du rapport

Documentation pas-à-pas avec captures d'écran et explications de chaque commande.

Mon avis personnel

Cette SAÉ m'a appris que derrière chaque site web, il y a une machine. Avant, pour moi, « héberger un site » c'était abstrait. Là j'ai vraiment installé un serveur, j'ai vu Apache servir mon premier index.html, et j'ai compris ce qu'est un port, un service système, un fichier de configuration. Cette base m'a beaucoup servi pendant mon stage chez Marchés BTP quand j'ai dû installer l'environnement de dev sur le Mac des fondateurs.
